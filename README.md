# EXE Penguin Bonk · hosted files

Hosted files for the **EXE Penguin Bonk** StreamElements widget by form&soul.exe (v1.0.1).

- `engine/penguinbonk-engine.js` — widget engine
- `engine/penguinbonk-presenter.js` — pixel-art presentation (ice block, bonks, plaque, colony bar, gags, collection shelf)
- `theme/` — 24 penguins + shiny + optional Christmas outfits, ice blocks, interface art, sound effects (`sfx/`), theme.json
- `fonts/` — Silkscreen (SIL Open Font License 1.1, see OFL-Silkscreen.txt)
- `index.html` — live preview

These files are loaded by the widget at runtime. Do not rename or move them.
